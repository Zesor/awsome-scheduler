Getting started / Introduction

Introduction

CalendarKit Pro is a complete, accessible calendar for React. One component, its own styles, no setup.

Installation #

npm   pnpm   yarn   bun
npm install calendarkit-pro

React 18 or 19 is the only requirement. Upgrading from 1.x? See Migrating from 1.x.

Quick start #

Give the calendar its events and let it keep them. That is the whole setup: the styles come with the component.

MyCalendar.tsx
import { Scheduler } from 'calendarkit-pro';

export function MyCalendar() {
  return (
    <div style={{ height: 720 }}>
      <Scheduler defaultEvents={events} onEventsChange={(next) => save(next)} />
    </div>
  );
}

Keeping the events in your state #

To own the list (to sync it with an API, for example), pass events and update it from the callbacks.

Next.js and server rendering #

calendarkit-pro is marked "use client", so it can be imported from a Server Component page.

Core concepts #

EventsThe CalendarEvent shape: dates, all-day, recurrence. Views and layoutsMonth to resource, Classic, Focus, Flow. Calendars and resourcesColours, toggles, rows in the resource view. CallbacksCreate, update, delete, drop, resize, every change.
